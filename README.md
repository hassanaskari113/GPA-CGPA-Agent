# GPA/CGPA Agent

A conversational agent for PUCIT BS(CS) students to calculate semester GPA, project CGPA, and plan for a target CGPA. Built with LangChain and Groq.

## Setup
1. `pip install -r requirements.txt`
2. Copy `.env.example` to `.env` and add your Groq API key
3. Run with `python agent.py`
